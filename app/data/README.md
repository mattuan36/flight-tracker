# Bundled data

`common-passwords.txt` is the 10,000-entry `10k-most-common.txt` list from
[SecLists](https://github.com/danielmiessler/SecLists), fetched from
`Passwords/Common-Credentials/10k-most-common.txt`.

SecLists is MIT licensed. It is used only to reject obviously bad passwords;
matching is case-insensitive and exact, so it is a floor, not a strength meter.
